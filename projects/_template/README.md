# Example project (template)

Copy this folder to `projects/<your-project-id>/` and replace placeholders in `project.json`.

Add `sessions/`, `notes/`, and a **client-side** `sync-music-from-kaiser.js` (or equivalent) in the game repo; register it under `clients` in `project.json`.

See [`../README.md`](../README.md) for the shared `projects/` layout.
